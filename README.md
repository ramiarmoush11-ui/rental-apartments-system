# Rental Apartments System

A Laravel REST API for a rental apartment booking system.

The system allows users to register as renters or apartment owners, browse available apartments, make reservations, manage their bookings, and maintain their profiles.

## Features

- User registration and authentication
- Renter and apartment owner roles
- Apartment browsing and filtering
- Filter apartments by location, price, and specifications
- Apartment details and owner information
- Create, update, and cancel reservations
- Prevent reservation conflicts
- View current, previous, and cancelled reservations
- Apartment ratings
- Notifications for reservation status changes
- Favorite apartments
- Arabic and English support
- Wallet and payment management
- Admin dashboard and user management

## Technologies

- Laravel
- PHP
- PostgreSQL
- Laravel Sanctum
- REST API

## Project Structure

The project follows Laravel's standard structure and separates API logic into controllers, models, requests, resources, traits, and database components.
